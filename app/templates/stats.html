What these mean

  • Median time to delete: how long a published image stays online after Buffer sends its post. The cleanup job wakes at each post's due time instead of polling, so this stays at a couple of minutes.
  • Buffer status checks per post: how many times we ask Buffer about a post before we're done with it. Around 1 means one check per post. Checks are batched, up to 30 posts per API request, so actual API calls are fewer still.
  • Storage freed: the total size of images we deleted, because the post no longer needed them.
